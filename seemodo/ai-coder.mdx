# AI Coder

The AI Coder is Seemodo's conversational development interface. Available in the Project Editor (`/projects/[id]`), it lets you build complete applications through chat — like having a developer who builds what you describe.

## The Project Editor

When you open a project, you see:

| Panel | Purpose |
|-------|---------|
| **Chat Panel** (left) | Your conversation with the AI. Write instructions, see responses. |
| **Preview Panel** (right) | Live preview of your running application |
| **Top Bar** | Back button, project name, Publish, GitHub, Share buttons |

### Resizable panels

Drag the divider between chat and preview to adjust panel widths.

## Chatting with the AI

Type what you want and press Enter. The AI:

1. Reads your message and understands the intent
2. Plans what code changes are needed
3. Writes/modifies files in your project
4. Your live preview updates automatically via hot-reload

### File mentions with @

Type `@` in the chat to reference specific files. An autocomplete menu shows your project files. This helps the AI focus on the right file when you need a specific change.

### Suggestion buttons

After each AI response, context-aware suggestion buttons appear. Click them for logical next steps without typing.

### Task progress

During complex operations, the AI shows a task list with checkboxes indicating progress — so you always know what's happening.

## Chat History

Click the **History** button in the top bar to browse all past conversations and messages for your project.

## Visual Edits

Click the **paintbrush icon** in the top bar to switch to Visual Edit mode. This lets you:

- Click elements directly in the preview
- Modify properties (text, color, spacing) visually
- See changes applied immediately

## The live preview

The right panel shows your running application. You can:

- **Interact** with it (click buttons, fill forms, navigate pages)
- **See real-time updates** as the AI makes changes
- **Inspect elements** in visual edit mode

The sandbox automatically starts when you open a project and stays running while you work.

## Tips for effective development

<Tip>
Be specific about what you want. Instead of "make it better", try "increase the font size of the title to 24px and add a blue border to the card."
</Tip>

- **One feature at a time** works better than asking for 10 things at once
- **Describe the end result** rather than implementation steps
- **Reference what exists** — "the button in the header" or "the pricing card"
- **Mention context** — "this is a food delivery app" helps the AI make better content decisions
