# Credits & Pläne

Seemodo nutzt ein Credit-System. Jede KI-Aktion kostet Credits. Dein Plan bestimmt die monatlichen Credits und verfügbaren Features.

## Pläne

<Tabs>
  <Tab title="Free">
    **0 €/Monat**
    
    - 100 monatliche Credits
    - HiFi UI Generierung
    - Wireframe Generierung
    - Code exportieren
    - Screen Flows (max. 3 Screens)
  </Tab>
  <Tab title="Standard">
    **12 €/Monat** (oder 9 €/Monat bei jährlicher Zahlung — 25 % Rabatt)
    
    - 420 monatliche Credits
    - Alles aus Free, plus:
    - Design Review
    - Predictive Heatmap
    - Screen Flows (max. 5 Screens)
  </Tab>
  <Tab title="Pro">
    **22 €/Monat** (oder 16,50 €/Monat bei jährlicher Zahlung — 25 % Rabatt)
    
    - 1.200 monatliche Credits
    - Alles aus Standard, plus:
    - Unbegrenzte Screen Flows
    - Image-to-Design
    - Section Edit
  </Tab>
  <Tab title="Teams">
    **31 €/Monat pro Benutzer** (oder 23,25 €/Monat jährlich — 25 % Rabatt)
    
    - 1.600 monatliche Credits pro Benutzer
    - Alles aus Pro, plus:
    - Geteilter Credit-Pool
    - Eigene Komponenten importieren
    - Custom Integration
    - Custom Onboarding
    - Plätze und Rollen
    - Priority Support
  </Tab>
</Tabs>

## Credit-Kosten pro Aktion

| Aktion | Credits |
|--------|---------|
| HiFi-Screen generieren | 6 |
| Wireframe generieren | 3 |
| Screen bearbeiten (KI-Edit) | 4 |
| Code exportieren | 2 |

<Note>
Deep Design und Max Mode erhöhen den Credit-Verbrauch für höhere Qualität.
</Note>

## Extra-Credits kaufen

| Credits | Preis |
|---------|-------|
| 360 | 18 $ |
| 720 | 34 $ |
| 1.440 | 63 $ |
| 2.880 | 118 $ |

Extra-Credits verfallen nie und werden erst nach deiner monatlichen Zuweisung verbraucht.

## Guthaben prüfen

Dein Credit-Guthaben ist immer im Top Header sichtbar:

⭐ **verfügbar** / **gesamt**

Klick darauf um das Account-Modal zu öffnen mit:

- Aktuelles Guthaben (monatlich + extra)
- Credit-Nutzungsverlauf
- Credit-Pakete kaufen
- Abonnement verwalten

## Abonnement verwalten

Unter Account-Einstellungen → **Plan verwalten**:

- Aktuellen Plan und Abrechnungszyklus sehen
- Upgraden oder downgraden
- Zwischen monatlicher und jährlicher Abrechnung wechseln
- Rechnungen und Billing-Verlauf einsehen
