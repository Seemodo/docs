# Projekte

Jede Anwendung in Seemodo ist ein Projekt. Projekte enthalten deinen Code, Chat-Verlauf, Sandbox-Status und Deployment-Konfiguration.

## Projekte erstellen

### Vom Dashboard

1. Klick auf **+**
2. Optional beschreiben was du bauen willst
3. Der Projekt-Editor öffnet sich und die KI beginnt

### Aus einem Template

Klick auf ein Template im Dashboard — fertige Vorlagen für:

- Admin Dashboard
- E-Commerce Store
- Chat-Anwendung
- Blog / CMS
- Portfolio
- Task Manager
- Kalender-App
- Bildergalerie
- Dokumentations-Seite

## Projekte organisieren

### Ordner

Erstelle Ordner um verwandte Projekte zu gruppieren:

1. Klick auf das **Ordner-Icon** in der Dashboard-Sidebar
2. Ordner benennen
3. Projekte in Ordner ziehen oder über Kontextmenü → **In Ordner verschieben**

### Favoriten

Markiere wichtige Projekte mit dem **Stern-Icon** für schnellen Zugriff.

### Suche

Nutze das Suchfeld oben im Dashboard um Projekte nach Name zu finden.

## Projekt-Einstellungen

Öffne Projekt-Einstellungen per Klick auf den **Projektnamen** (mit Pfeil) im Editor-Toolbar. Das **Projekt-Einstellungen-Modal** öffnet sich.

### Übersicht & Statistiken

| Stat | Beschreibung |
|------|-------------|
| **Projektname** | Editierbarer Anzeigename |
| **Beschreibung** | Kurze Projektbeschreibung |
| **Erstellt** | Erstellungsdatum |
| **Bearbeitungen** | Anzahl KI-Edits |
| **Nachrichten** | Gesamt-Chat-Nachrichten |
| **Tool-Aufrufe** | Anzahl KI-Tool-Ausführungen |
| **Credits verbraucht** | Gesamte Credits für dieses Projekt |
| **Deployed URL** | Link zur Live-Deployment |

### Vollständige Projekt-Einstellungen

Klick **Vollständige Einstellungen öffnen** für `/projects/[id]/settings`:

| Bereich | Details |
|---------|---------|
| **Allgemein** | Name, Beschreibung, Custom-Domain-Pfad |
| **Integrationen** | Seemodo Cloud, externe Services |
| **Transfer** | Projekt an anderen Nutzer übertragen |
| **Gefahrenzone** | Projekt dauerhaft löschen |

## Teilen & Zusammenarbeit

### Projekt teilen

Klicke **Teilen** im Projekt-Editor:

1. E-Mail der Person eingeben
2. Zugriffsebene wählen: **Editor** oder **Viewer**
3. **Hinzufügen** klicken

### Sichtbarkeit

- **Privat** — Nur du und eingeladene Mitarbeiter
- **Öffentlich** — Jeder mit dem Link kann es sehen
