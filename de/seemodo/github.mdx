# GitHub Integration

Verbinde Seemodo-Projekte mit GitHub für Versionskontrolle, Zusammenarbeit und Code-Portabilität.

## GitHub-Konto verbinden

<Steps>
  <Step title="Einstellungen → GitHub öffnen">
    Oder Git-Icon in einem Projekt-Editor klicken.
  </Step>
  <Step title="Connect GitHub klicken">
    Weiterleitung zu GitHub zur Autorisierung.
  </Step>
  <Step title="Zugriff gewähren">
    Wähle welche Organisationen und Repositories Seemodo nutzen darf.
  </Step>
  <Step title="Verbindung bestätigt">
    GitHub-Username und Avatar erscheinen. Grüner Punkt am Git-Button im Editor.
  </Step>
</Steps>

## Projekt mit Repository verknüpfen

<Steps>
  <Step title="Projekt öffnen">
    Zum Projekt-Editor navigieren.
  </Step>
  <Step title="GitHub-Icon in der Toolbar klicken">
    GitHub-Dialog öffnet sich.
  </Step>
  <Step title="Organisation wählen">
    Persönliches Konto oder Organisation aus dem Dropdown wählen.
  </Step>
  <Step title="Verbindung bestätigen">
    Ein Bestätigungsdialog erklärt dass das Projekt mit GitHub unter der gewählten Organisation synchronisiert wird. Klick **Transfer anyway** zum Bestätigen.
    
    Seemodo erstellt automatisch ein privates Repository (benannt nach dem Projekt).
  </Step>
</Steps>

## Code synchronisieren

### Push zu GitHub

1. **Push** klicken
2. Seemodo committet und pusht alle aktuellen Dateien
3. Erfolgsmeldung mit Commit-Details

### Pull von GitHub

1. **Pull** klicken
2. Remote-Änderungen werden in die Sandbox gemergt
3. Live-Vorschau aktualisiert sich

### Diff ansehen

Vor dem Push Änderungen prüfen:

1. **View Diff** klicken
2. Diff-Viewer zeigt: hinzugefügte (grün), geänderte (gelb), gelöschte (rot) Dateien
3. Zeilenweise Vergleiche

## Clone URLs

| Format | Beispiel |
|--------|---------|
| **HTTPS** | `https://github.com/org/repo.git` |
| **SSH** | `git@github.com:org/repo.git` |
| **CLI** | `gh repo clone org/repo` |

Kopier-Icon neben jeder URL klicken.

## Verbindung trennen

1. GitHub-Dialog öffnen
2. **Disconnect** klicken
3. Bestätigen

Repository bleibt auf GitHub — nur die Sync-Verbindung wird entfernt.

## Git im Visual Designer

Das Sandbox Panel hat einen **Git-Tab**:

| Feature | Beschreibung |
|---------|-------------|
| **Branch** | Aktuellen Branch anzeigen |
| **Änderungen** | Geänderte Dateien mit Status-Icons |
| **Commit** | Nachricht schreiben und alle Änderungen committen |
| **History** | Letzte 20 Commits mit Hash, Autor, Datum, Nachricht |
| **Diff** | Commit anklicken für unified Diff |
| **Auto-Refresh** | Status pollt alle 10 Sekunden |
