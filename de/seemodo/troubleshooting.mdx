# Fehlerbehebung

## Generierungs-Probleme

<AccordionGroup>
  <Accordion title="Generierung bleibt stecken oder dauert zu lange">
    - Internetverbindung prüfen
    - Seite neu laden und erneut generieren
    - Bei Max Mode ist längere Dauer normal
    - Credit-Guthaben prüfen — bei 0 Credits stoppt die Generierung
  </Accordion>
  <Accordion title="Ergebnis passt nicht zum Prompt">
    - Sei spezifischer im Prompt (Farben, Layout, Inhalte explizit nennen)
    - **Enhance**-Button nutzen um den Prompt vor der Generierung zu verbessern
    - Referenzbilder für visuelle Orientierung hochladen
    - **Deep Design** für durchdachtere Ergebnisse aktivieren
  </Accordion>
  <Accordion title="Generierter Screen zeigt Fehler">
    - Mit KI bearbeiten: "Behebe die Fehler auf dieser Seite"
    - Sandbox Panel → Vite Logs für spezifische Fehlermeldungen öffnen
    - Terminal-Tab für Konsolen-Ausgabe nutzen
  </Accordion>
</AccordionGroup>

## Sandbox-Probleme

<AccordionGroup>
  <Accordion title="Sandbox startet nicht">
    - Bis zu 30 Sekunden warten — Sandbox-Start braucht Zeit
    - Seite neu laden und erneut versuchen
    - Aktives Abonnement oder Credits prüfen
  </Accordion>
  <Accordion title="Vorschau zeigt weiße/leere Seite">
    - Sandbox Panel → Vite Logs auf Build-Fehler prüfen
    - KI fragen: "Die Seite ist leer, bitte behebe alle Fehler"
    - Im Terminal "Restart" nutzen
  </Accordion>
  <Accordion title="Änderungen erscheinen nicht in der Vorschau">
    - Hot-Reload handhabt das normalerweise automatisch
    - KI fragen: "Starte den Dev-Server neu"
    - Terminal öffnen und Restart-Befehl ausführen
  </Accordion>
</AccordionGroup>

## Deployment-Probleme

<AccordionGroup>
  <Accordion title="Deployment schlägt fehl">
    - Fehlermeldung im Deploy-Panel prüfen
    - Häufige Ursache: Build-Fehler im Code — zuerst über KI-Chat beheben
    - Nach Fehlerbehebung erneut deployen
  </Accordion>
  <Accordion title="Deployed App funktioniert nicht korrekt">
    - Zuerst prüfen ob die App in der Vorschau funktioniert
    - Manche Features die Server-Logik brauchen funktionieren nicht in statischen Deployments
  </Accordion>
</AccordionGroup>

## Account & Billing

<AccordionGroup>
  <Accordion title="Credits werden nicht erneuert">
    - Monatliche Credits setzen sich am Abrechnungsdatum zurück
    - Unter Account-Einstellungen → Credits-Information das Reset-Datum prüfen
    - Gekaufte Extra-Credits verfallen nicht
  </Accordion>
  <Accordion title="Login nicht möglich">
    - Passwort über Login-Seite zurücksetzen
    - Browser-Cookies löschen und erneut versuchen
    - Gleiche Login-Methode wie bei der Registrierung nutzen
  </Accordion>
</AccordionGroup>

## GitHub Integration

<AccordionGroup>
  <Accordion title="Verbindung zu GitHub nicht möglich">
    - Seemodo auf GitHub autorisiert?
    - Berechtigungen für die Ziel-Organisation prüfen
    - Trennen und neu verbinden versuchen
  </Accordion>
  <Accordion title="Push/Pull schlägt fehl">
    - Auf Merge-Konflikte prüfen
    - Ziel-Branch existiert?
    - GitHub-Token noch gültig?
  </Accordion>
</AccordionGroup>

## Seemodo Cloud

<AccordionGroup>
  <Accordion title="Cloud-Aktivierung fehlgeschlagen">
    - Zuerst eine aktive Sandbox sicherstellen
    - Cloud-Modal schließen und neu öffnen
    - Internetverbindung prüfen
  </Accordion>
  <Accordion title="Datenbank-Queries funktionieren nicht">
    - Seemodo Cloud ist aktiviert? (Cloud-Icon aktiv?)
    - SQL-Syntax im Datenbank-Manager prüfen
    - KI fragen: "Die Datenbank-Abfrage für Benutzer funktioniert nicht"
  </Accordion>
</AccordionGroup>
