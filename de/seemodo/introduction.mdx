# Was ist Seemodo

Seemodo ermöglicht es dir, komplette Web-Anwendungen zu erstellen, indem du einfach beschreibst, was du willst. Schreibe einen Prompt und Seemodo generiert funktionsfähigen Code — mit einer Live-Vorschau in Echtzeit.

Keine Programmierkenntnisse nötig. Nur deine Idee.

## Was du bauen kannst

- **SaaS-Anwendungen** — Dashboards, CRM, Projektmanagement-Tools
- **E-Commerce** — Shops, Produktkataloge, Checkout-Flows
- **Landing Pages** — Marketing-Seiten, Portfolios, Funnels
- **Mobile Apps** — Responsive Mobile-First-Designs
- **Interne Tools** — Admin-Panels, Analytics, Datenverwaltung
- **Social Platforms** — Chat-Apps, Foren, Community-Tools

## Zwei Wege zum Bauen

### Visual Designer (`/start`)

Ein Canvas-basierter Workspace für visuelle Screen-Generierung. Ideal für:
- Einzelne Screens oder komplette Flows designen
- Wireframing vor dem Bauen
- Landing Pages mit vielen Sektionen
- Schnelles Prototyping mit Referenzbildern

### Projekt-Editor (`/projects/[id]`)

Eine vollständige Entwicklungsumgebung mit KI-Chat. Ideal für:
- Komplette Anwendungen mit mehreren Seiten
- Iteratives Arbeiten über Zeit
- Code, Dateien und Live-Vorschau nebeneinander
- Datenbank-Anbindung, APIs und Deployment

## Kernfunktionen

| Feature | Was es tut |
|---------|-----------|
| **KI-Generierung** | Beschreibe einen Screen, erhalte produktionsreifen Code |
| **Live-Sandbox** | Deine App läuft live mit Hot-Reload bei Änderungen |
| **KI-Chat** | Fordere Änderungen per Nachricht an — die KI setzt sie um |
| **Autoflow** | KI teilt deine App-Idee in Screens auf und generiert alle |
| **Seemodo Cloud** | Ein-Klick-Datenbank, Auth und File-Storage |
| **Deployment** | App mit einem Klick veröffentlichen |
| **GitHub Sync** | Zwei-Wege-Sync mit GitHub-Repositories |
| **Team-Zusammenarbeit** | Projekte teilen und gemeinsam arbeiten |
| **Export** | Code jederzeit als ZIP herunterladen |
